Settings

GitHub sync

Not connected

Everything is saved on this iPhone and works with no internet. With GitHub sync on, every change is also committed as streak.json to your private repo, including check-in, check-out and duration for each day. The token stays only on this phone.

Pause days

Paused days neither break nor grow the streak. You get 30 pause days in any 12-month span, for today or future dates only. If you still check out on a paused day, it counts as a normal done day.

App icon

iPhone reads the icon only when you add the app to the home screen, so a new icon has to be published to the app repo first. Your GitHub token needs access to that repo as well. After publishing, wait a minute, delete the old home-screen icon and add it again.

iPhone widget

  1. Install the free Scriptable app from the App Store.
  2. Tap + in Scriptable, paste the script, name it Go.
  3. Run it once and paste your GitHub token when asked.
  4. Long-press the home screen, add a Scriptable widget, choose Go.
